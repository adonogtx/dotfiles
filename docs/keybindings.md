# Keybindings

SUPER works like Command on a Mac. Vim keys move focus. Source: `config/hypr/modules/binds.lua`.

## Apps

| Keys | Action |
|---|---|
| Super + Return | Ghostty |
| Super + Space | Spotlight |
| Super + B | Brave |
| Super + E | Files (Nautilus) |
| Super + D | Doom Emacs (emacsclient) |
| Super + I | IntelliJ IDEA |
| Super + C | Clipboard history (last 50) |
| Super + Shift + C | Wipe clipboard history |
| Ctrl + Space | English and Japanese (fcitx5) |

## Windows

| Keys | Action |
|---|---|
| Super + Q | Close window |
| Super + F | Fullscreen |
| Super + V | Float or tile |
| Super + T | Flip the split |
| Super + H J K L | Focus left, down, up, right |
| Super + Shift + H J K L | Move window |
| Super + R, then H J K L | Resize; Escape to leave |
| Super + drag | Move with the mouse (left) or resize (right) |

## Workspaces

| Keys | Action |
|---|---|
| Super + 1 to 5 | Go to workspace |
| Super + Shift + 1 to 5 | Send window to workspace |
| Super + Tab | Previous workspace |
| Super + scroll | Next or previous workspace |
| Super + S | Scratch workspace |
| Three fingers sideways | Next or previous workspace |

## Capture

| Keys | Action |
|---|---|
| Super + Shift + S | Screenshot of a region (MX Keys Mini F8) |
| Print | Screenshot of the screen |
| Super + Shift + R | Start or stop recording a region |

## System

| Keys | Action |
|---|---|
| Super + Ctrl + Q | Lock (like Ctrl + Cmd + Q) |
| Super + N | Night Shift |
| Super + Shift + W | Control Center, Wi-Fi |
| Super + Shift + A | Control Center, Sound |
| Super + Shift + B | Control Center, Bluetooth |
| Super + Shift + E | Log out |
| Volume, brightness, media keys | Work everywhere, also on the lock screen |
