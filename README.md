# dotfiles

simple, minimal and zen dotfiles for my personal arch linux setup.

the goal is to keep the environment calm, predictable and free from unnecessary distractions.

## setup

- window manager: i3 on x11
- bar and launcher: polybar and rofi
- terminal and shell: kitty and bash
- compositor and notifications: picom and dunst
- input method: fcitx5
- theme: gruvbox

## requirements

### core

`arch linux` · `x11` · `i3` · `git` · `gnu stow`

### interface

`polybar` · `kitty` · `rofi` · `dunst` · `picom`

### system

`pipewire` · `wireplumber` · `polkit-gnome` · `fcitx5`

### utilities

`fastfetch` · `feh` · `xss-lock` · `i3lock-color` · `brightnessctl` · `playerctl` · `pavucontrol` · `thunar` · `flameshot` · `udiskie`

### fonts

`lilex nerd font` · `noto sans cjk jp`

## note

these dotfiles are made for my personal use.

do not copy them blindly.

review every file, dependency, path and shortcut before using them on your own system.
