# gus-bar

The Quickshell bar and its panels, in Gruvbox Material. `dot apply` copies this folder to
~/.config/quickshell, so a plain `qs` starts it; Hyprland does that on login.

| Part | What it shows |
| --- | --- |
| Left | Kamon and workspaces 1 to 5 (yellow square on the active one) |
| Center | 11月2日(月) and the time, plus 稽古 23m while a keiko runs; click opens the calendar |
| Right | Bluetooth, Wi-Fi, sound, display and battery; each opens its panel |

Restart after editing: SUPER + CTRL + R
